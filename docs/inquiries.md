     원금균등으로 보이지만, 원금균등과 원리금균등은 초기 상환 부담이 크게 다르므로 못 박아 둘 필요가 있다.

     - **원리금균등**: 매 회차 **총 상환액이 고정**. 초기에는 이자 비중이 크고 원금이 천천히 준다.

### ✅ [해결] — 다시 묻지 않음 (3건)

**C-16. ✅ 원금 감면율은 어떻게 결정되나요?** — 해결

- **대상 정책:** 새출발기금 부실차주 / 부실우려차주. JSON의 `원금감면율_추정` 필드가 이 값을 쓴다.
- **왜 필요했나:** `cashflow.py`의 부채감면 분기가 `감면액 = 기존 부채 × 감면율`로 계산한다. 이 값 하나가 순부채 축을 좌우해 회복불가 국면의 추천 순위를 통째로 바꾼다. 우리가 웹 검색으로 넣은 0.8은 근거가 약한 추정치였다.

- **확인 내용** (금융위 새출발기금 보도자료 2026.2.26, 참고1 및 본문 III-①-2)
  - **부실차주**: 신용대출 중 **보유재산가액을 초과하는 순부채**에 대해 **60~80% 감면**
    - 총채무 1억원 이하 + 중위소득 60% 이하 부실차주, 사회취약계층: 최대 **90%**
    - 취·창업 프로그램 이수 시 최대 **10%p 추가 감면**(최대 90%, 취·창업 중복이수는 합산 제외)
  - **부실우려차주는 원금 감면이 없다.** "이자조정 — 연체기간에 따라 이자율 차등 조정"만 적용
  - **담보대출은 원금조정 없이 이자·기간 조정만**
  - 상환 구조: 부실차주·부실우려차주 모두 **거치 0~12개월 + 분할 1~10년**,
    담보대출 거치 0~36개월 + 분할 1~20년, 취약계층·저소득 부실차주 거치 최대 3년 + 분할 최대 20년

- **시뮬레이터에 미치는 영향 — 세 가지 수정이 필요하다**
  1. **감면 기준이 총채무가 아니라 순부채(보유재산 초과분)다.** 현재 코드는 총채무에 감면율을 곱한다.
     부채 6,000만원에 재산 2,000만원이면 순부채 4,000만원에만 적용되어 감면액이 절반 가까이 줄어든다.
  2. **신용대출만 대상이고 담보대출은 제외된다.** 현재는 부채를 하나로 뭉뚱그려 구분이 없다.
  3. **부실차주 상환 조건이 틀렸다.** 현재 JSON은 거치 36개월 + 분할 240개월인데 이는 **취약계층 기준**이다.
     일반은 거치 0~12개월 + 분할 1~10년이므로, 36개월 시뮬레이션 안에서 상환이 시작된다.
     현재 값을 쓰면 거치 중이라 상환이 0으로 잡혀 생존 개월수가 과대평가된다.

- **반영 방침(확정):** 감면율을 **범위 하한 0.6**으로 두고, 화면에는 "재산·소득에 따라 60~80%"로 범위를 표시한다.
  개인 상황에 달린 값이라 코드가 하나로 정할 수 없고(5.5 "정량으로 고를 수 없으면 고르지 않는다"),
  하한을 쓰면 보수적이라 함정을 과소 경고하지 않는다.
  **재산·담보대출은 이 정책 후보가 조합에 포함될 때만 추가로 묻고, 모르면 건너뛸 수 있게 한다.**

  t=6   새출발기금 채무조정 확정

## D. 신용회복위원회
**☎ 1600-5500**

> **대상 정책:** 현재 JSON 미수록. E-31이 확인되면 3종을 추가한다.

### ❓ [미해결] — 확인 필요 (2건)

**E-31. ★★★ 3종에 신청하면 어떤 빚이 채무조정 대상에 들어가나요?**

- **어떤 정책:** 신용회복위원회 **신속채무조정 · 프리워크아웃 · 개인워크아웃**
  (현재 JSON 미수록 — 확인되면 정책 3개 추가)
- **무엇을 묻는가:** 신청 시 **조정 대상 채무의 범위**
  ```
  ① 사업자 명의 대출        소진공 정책자금 · 은행 사업자대출 · 보증서 대출 등
  ② 사업 용도 가계대출       개인 명의로 받았으나 사업에 쓴 신용대출·카드론
  ③ 둘을 같이 가진 경우      합산 조정인지 별도인지
  ④ 금액 상한              있는지, 얼마인지
  ⑤ 폐업 필수 여부          영업 중에도 신청 가능한지
  ```
- **🔴 왜 이게 갈림길인가**

  신복위는 본래 **개인 채무자**를 돕는 기구다. 개인의 가계대출 조정이 본업이라
  **사업자대출이 대상에 들어가는지가 불확실하다.**
  우리 사용자는 소상공인이고 빚 대부분이 사업자대출이다.
  ```
  사업자대출 포함   →  조정 효과가 크다. 정책 3개를 수록할 가치가 있다
  가계대출만       →  소상공인에게 실효가 거의 없다. 수록해도 무의미하다
  ```
  **②를 따로 물어야 한다.** "사업자대출"만 물으면 상담원이 명의 기준으로만 답할 수 있는데,
  실제로 소상공인이 많이 쓰는 것은 개인 명의 대출을 사업에 돌려쓴 경우다.

- **비교 기준 — 새출발기금은 이미 확인됐다**
  ```
  협약 금융회사의 총 15억원 이하 대출
    담보·보증 10억 / 무담보 5억
    사업자대출 + 사업용도 가계대출 모두 포함
  ```
  "사업용도 가계대출"까지 포함하는 것이 핵심이다. 신복위 3종이 이만큼 넓은지가 관건이다.

- **🔴 왜 ★★★인가 — 채무조정 축이 사실상 죽어 있다**
  ```
  상환연장제도      일시적자금난 · 개선여지   후보 1개
  새출발기금        회복불가                후보 1개
  ```
  두 정책의 국면이 겹치지 않아 **어느 국면에서 보든 채무조정은 항상 딱 1개**다.
  "어느 채무조정이 나은가"를 비교할 대상이 없어 조합 최적화가 이 축에서 작동하지 않는다.

  신복위 3종은 연체 단계별로 갈려 국면마다 하나씩 붙는다.
  ```
  연체 전 · 단기 연체    신속채무조정      일시적자금난 · 개선여지
  연체 31~89일          프리워크아웃      개선여지
  연체 90일 이상         개인워크아웃      회복불가 (새출발기금과 경쟁)
  ```
  특히 연체 90일 이상에서 새출발기금과 개인워크아웃이 **경쟁 관계**가 되어,
  그때 비로소 두 축 비교가 의미를 가진다.

- **이미 확인된 것:** 희망리턴패키지 공고문에 신복위 3종이 개인사업자 대상 제도로
  언급되어 있어 개인사업자 이용 자체는 가능해 보인다. **대상 채무의 범위가 관건.**

**📖 먼저 찾아볼 곳 — 홈페이지에 명시되어 있을 가능성이 높다**
1. **신용회복위원회 `ccrs.or.kr`** → 채무조정제도 →
   신속채무조정 / 프리워크아웃 / 개인워크아웃 각 페이지의 **「조정대상 채무」** 항목
2. 신복위 **채무조정 제도 비교표** (3종을 한 표로 정리한 페이지가 있다)
3. 검색어: `신용회복위원회 조정대상 채무 사업자대출` · `프리워크아웃 사업자대출 포함` ·
   `개인워크아웃 사업용도 대출` · `신속채무조정 개인사업자 신청`

## 문의 시 유의사항

- **같은 질문을 양쪽 기관에 교차 확인**할 것 (A-1 ↔ B-10). 기관마다 자기 자금 기준으로만 답할 수 있음
- 답변을 들으면 **근거 문서(공고문 조항, 운영규정)를 물어볼 것**. "가능합니다"만으로는 데이터에 확정값으로 넣기 어려움
- 답이 애매하면 데이터에 **"확인필요"로 유지**하고, 서비스에서는 해당 조합에 "중복 가부는 기관 확인 필요" 주의 문구를 붙이는 방식으로 처리
- 통화 후 **해당 문항 바로 아래에 답변을 기록**할 것. 답변과 함께 **그것이 코드·데이터에 미치는 영향**까지 적어두면 나중에 반영할 때 찾기 쉽다 (해결된 문항은 ★ 대신 ✅로 표시)
