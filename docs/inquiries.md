## A. 소상공인시장진흥공단 (소진공)
**☎ 1533-0100 (소상공인통합콜센터) → 내선 1번**
※ 맞춤형 정책자금·채무조정제도·재기지원 상담 담당

**A-1. ★★★ 소진공 정책자금과 서울시 중소기업육성자금을 동시에 받을 수 있나요?**
- 배경: 재원이 다르므로(중앙정부 vs 서울시 기금) 원칙적으로 가능하다는 정보가 다수이나, 공고문에 명시적 조항을 찾지 못함
- 확인 포인트: 동시 신청 가능 여부 / 한쪽을 받으면 다른 쪽 한도가 줄어드는지 / 신청 순서 제약이 있는지

**A-2. ★★ 소진공 자금끼리 동시에 2건 이상 받을 수 있나요?**
- 예: 일반경영안정자금 + 긴급경영안정자금
- 배경: 공고문에 "총 융자한도 운전자금 5억(긴급경영안정자금은 별도 운용)"이라 되어 있어 한도 내 복수 가능해 보이나, 자금별 택일 규정이 따로 있는지 불명확
- 확인 포인트: 한도 내라면 복수 가능한지 / 자금 성격이 겹치면(둘 다 운전자금) 제한되는지

**A-3. ★★★ 새출발기금 채무조정 중이거나 이행 완료한 사람이 신규 정책자금을 신청할 수 있나요?**
- 배경: 재도전특별자금 자격에 "채무조정 이후 미납 없이 6회차 이상 납입" 조건이 있어 **완전 배타는 아닌 것으로 보임**. 다른 자금(일반경영안정 등)도 동일한지 확인 필요
- 확인 포인트: 채무조정 이행 중 신청 가능 여부 / 자금별로 다른지 / 성실상환 몇 회차부터인지

**A-4. ★ 경영안정 바우처(25만원)와 정책자금을 중복으로 받을 수 있나요?**
- 배경: 초기 자료 수집 시 "중복 가능(매출 1억 400만원 미만)"이라는 정보를 얻었으나 공고문에서 근거를 찾지 못해 데이터에 "확인필요"로 표시해 둠

**A-5. ★★★ 긴급경영안정자금(일시적 경영애로)의 "매출 15% 이상 감소" 판정 기준을 정확히 알고 싶습니다.**
- 배경: 공고문에 "직전 매출과 직전전 매출(연도·반기·분기·월별) 비교를 통해 매출 15% 이상 감소"라고만 되어 있어 세부 판정 방식이 불명확. **이 서비스는 매출 추세로 "몇 개월 뒤 이 기준을 충족할지"를 예측하므로, 비교 방식이 다르면 결과가 완전히 달라짐**
- 확인 포인트:
  1. **연도·반기·분기·월별 네 가지 기준 중 하나만 충족해도 되는지**, 아니면 특정 기준이 정해져 있는지
  2. **월별 기준의 비교 대상** — 예를 들어 2026년 7월 매출을 ①2026년 6월(직전월)과 비교하는지 ②2025년 7월(전년 동월)과 비교하는지
  3. 매출 증빙은 어떤 자료 기준인지 (부가세 신고 / 카드 매출 / POS 등)
  4. **이 기준이 명시된 업무처리기준·심사 매뉴얼·운영규정이 있는지, 열람이나 사본 요청이 가능한지**
- ※ 4번을 반드시 물어볼 것. 구두 답변만으로는 예측 로직의 근거로 삼기 어려움

**A-6. ★★★ 매출이 15% 이상 감소한 소상공인은 일반경영안정자금과 긴급경영안정자금을 둘 다 지원받을 수 있나요?**
- 배경: 일반경영안정자금은 매출 요건이 없고, 긴급경영안정자금은 매출 15% 감소가 요건이므로 **자격상으로는 둘 다 해당됨**. 실제로 동시 수혜가 가능한지, 아니면 택일인지 확인 필요
- 확인 포인트: 동시 가능 여부 / 가능하다면 한도 합산 방식(긴급은 별도 한도 운용이라고 공고에 있음) / 신청 순서 제약

**A-7. ★★ 소진공 자금 중 "5년 이내(거치 2년 포함)"이 아닌 상환 구조의 상품이 있나요?**
- 배경: 확인한 자금은 대부분 5년/거치2년(대환대출만 10년) 구조. 서울시 자금은 1년거치·2년만기 일시상환 등 다양한데, 소진공에도 다른 구조가 있는지 확인
- 확인 포인트: 거치 1년 상품 유무 / 만기 일시상환 상품 유무 / 상환조건을 신청자가 선택할 수 있는 자금이 있는지
- **중요도:** 현금흐름 시뮬레이션의 상환 시작 시점 계산에 직결

**A-8. ★ 정책자금 신청 후 실행까지 통상 얼마나 걸리나요?**
- 배경: 대리대출/직접대출 방식에 따라 다를 것으로 예상. 서비스에서 "언제 돈이 들어오는지"를 안내할 수 있으면 유용

## B. 서울신용보증재단
**☎ 1577-6119**
※ 서울시 중소기업육성자금의 심사·보증서 발급 담당
※ 번호는 전체 통번호를 이어 붙임(B-9~13은 초기 작성분, B-20~24는 2026-08-06 공고문 확인 후 추가분)

**B-9. ★★ 서울시 중소기업육성자금의 세부자금끼리 중복 신청이 가능한가요?**
- 예: 경제활성화자금 + 재기지원자금
- 확인 포인트: 동시 가능 여부 / 총한도 합산 방식 / 성격이 겹치는 자금 간 제한

**B-10. ★★★ 서울시 자금과 소진공 정책자금을 동시에 받을 수 있나요?**
- ※ A-1과 같은 질문을 양쪽에 교차 확인 (기관마다 답이 다를 수 있음)

**B-11. ★★ 상환조건(1년거치 4년 / 2년거치 3년 / 2년만기 일시상환)은 신청자가 자유롭게 선택할 수 있나요?**
- 배경: 공고에 "택1"로 되어 있으나, 실제로 심사 과정에서 정해지는지 신청자가 고르는지 불명확
- 확인 포인트: 신청 시 선택 가능한지 / 심사 결과로 조정되는지 / 자금별로 선택지가 다른지
- **중요도:** 서비스에서 상환조건 선택 UI를 제공할 계획이라, 실제로 선택 불가능하면 기능을 바꿔야 함

**B-12. ★ 세부자금별 정확한 한도·금리·자격 요건**
- 대상: 경제활성화자금 / 희망동행자금(대환) / 취약사업자지원자금 / 포용금융자금 / 재기지원자금
- ※ 공고문(hwp)으로도 확인 가능하나 애매한 부분 보완용
- 확인 포인트: 소상공인 단독 대표 기준 한도 / 신용점수 하한 / 업력 요건

**B-13. ★ 안심통장(마이너스통장)은 다른 융자와 성격이 다른데, 중복 이용이 가능한가요?**
- 배경: 한도 대출이라 현금흐름 계산 방식이 다름. 서비스에 포함할지 판단용

**B-20. ★★★ 시중은행협력자금의 "이차보전"을 적용하면 소상공인이 실제로 부담하는 대출금리는 몇 %인가요?**
- 배경: 2026년 변경공고(제2026-1433호) 붙임1에 시중은행협력자금은 **"이차보전 1.8%" / "이차보전 2.5%"**로만 표기되어 있고 대출금리가 없음. 이차보전은 금리가 아니라 **은행 대출금리에서 서울시가 대신 부담하는 이자율(%p)**이므로, 은행 금리를 모르면 실제 부담 금리를 계산할 수 없음
- ※ 직접융자금(성장기반 3.0% / 긴급자영업 2.5% / 혁신형도약 3.0% / 재해 2.0%)은 공고문에 대출금리가 명시되어 있어 이 질문의 대상이 아님
- 확인 포인트:
  1. **경제활성화자금 기준, 이차보전 1.8% 적용 후 고객이 실제 내는 금리가 대략 몇 %인지** (최근 실행 사례 기준 범위로도 좋음)
  2. **협약 취급은행 목록** — 공고문에는 신속드림자금(카카오뱅크·케이뱅크 전용), 서울배달상생자금(신한은행)만 명시되어 있고 나머지는 은행이 표기되어 있지 않음
  3. 은행 대출금리의 **기준금리가 무엇인지** (COFIX / 금융채 1년물 등)와 가산금리 결정 방식
  4. 보증서담보 대출이므로 **신용점수에 따른 금리 편차가 어느 정도**인지
  5. 이차보전 **적용 기간**(공고상 "대출일로부터 4년/5년/7년 이내")이 끝난 뒤에는 금리가 어떻게 되는지
- **중요도:** 이 답을 못 얻으면 경제활성화·포용금융·희망동행·재기지원 등 **시중은행협력자금 전체를 시뮬레이션 대상에서 빼야 함**

**B-21. ★★★ 긴급자영업자금의 "매출액이 이전 분기·반기 대비 20% 이상 급감" 판정 기준을 정확히 알고 싶습니다.**
- 배경: 이 서비스는 매출 추세로 "몇 개월 뒤 이 요건을 충족할지"를 예측함. 소진공 긴급경영안정자금(15% 감소, 연/반기/분기/월)과 **기준율도 비교 단위도 달라** 별도 판정 로직이 필요함
- 확인 포인트:
  1. **분기 기준과 반기 기준 중 하나만 충족해도 되는지**, 아니면 둘 다인지
  2. **비교 대상** — 직전 분기 vs 직전전 분기인지, 전년 동분기인지
  3. 매출 증빙 자료 기준 (부가세 신고 / 카드매출 / POS 등)
  4. 이 기준이 명시된 **업무처리기준·심사 매뉴얼**이 있는지, 열람·사본 요청이 가능한지

**B-22. ★★ 긴급자영업자금의 지원대상 요건은 "택1"인가요?**
- 배경: 공고문에 ①생계형 영세 자영업자 ②여성가장·한부모 고용 기업 ③매출 20% 이상 급감 ④임차료 30% 이상 상승이 나열되어 있으나, 이 중 **하나만 충족하면 되는지(OR) 여러 개를 충족해야 하는지(AND)**가 명시되어 있지 않음
- 확인 포인트: OR인지 AND인지 / 요건별로 증빙서류가 다른지
- **중요도:** OR이면 매출 요건 미충족자도 자격이 생기므로 자격 필터 로직이 달라짐

**B-23. ★★ 직접융자금과 시중은행협력자금을 동시에 받을 수 있나요?**
- 예: 긴급자영업자금(직접융자) + 경제활성화자금(은행협력)
- 배경: B-9는 "세부자금끼리"를 물었으나, 재원 성격이 다른 **직접융자금(시 기금)과 시중은행협력자금** 사이에도 같은 제한이 적용되는지 별도 확인 필요
- 확인 포인트: 동시 가능 여부 / 총한도 합산 여부 / 보증한도가 공유되는지

**B-24. ★ "자금소진시까지" 접수인데, 분기별 한도 배분이 어떻게 운영되나요?**
- 배경: 공고문에 성장기반·긴급자영업·경제활성화·창업기업·일자리창출우수기업자금은 "연중 안정적 공급을 위해 분기별 한도를 배분"한다고 되어 있음. 서비스가 "지금 신청 가능한가"를 안내하려면 소진 여부를 알아야 함
- 확인 포인트: 분기 한도 소진 시 다음 분기까지 대기하는지 / 잔여 한도를 확인할 수 있는 경로가 있는지

## C. 새출발기금 (캠코 / 신용회복위원회)
**☎ 1660-1378 (새출발기금 콜센터)**

**C-14. ★★★ 새출발기금 채무조정을 신청·이행 중일 때 신규 대출(정책자금 포함)이 제한되나요?**
- 배경: 조합 생성의 하드 제약. 배타라면 "채무조정 + 신규 융자" 조합을 생성하지 말아야 함
- 확인 포인트: 신청 중 제한 / 확정 후 제한 / 성실상환 몇 회차 후 해제되는지

**C-15. ★★ 부실우려차주의 구체적 요건이 무엇인가요?**
- 배경: 부실차주는 "90일 이상 연체"로 명확하나, 부실우려차주는 "상환 어려움 예상"이라는 정성적 표현
- 확인 포인트: 연체 며칠부터 해당되는지 / 연체가 없어도 소득·매출 기준으로 해당될 수 있는지 / 판정 주체

**C-16. ★★ 원금 감면율은 어떻게 결정되나요?**
- 배경: "최대 80~90%(취약계층 90%)"로 알려져 있으나, 실제 적용률이 개인 상황에 따라 어떻게 갈리는지 불명확
- 확인 포인트: 감면율 산정 기준 / 부실우려차주도 원금 감면이 되는지(아니면 이자·기간 조정만인지)
- **중요도:** 현금흐름 시뮬레이션에서 채무조정 효과를 계산하는 핵심 값

**C-17. ★ 채무조정 신청 시 신용점수·공공정보 등록에 어떤 영향이 있나요?**
- 배경: 사용자에게 리스크로 안내해야 할 사항

**C-18. ★★ 채무조정 프로그램을 동시에 2개 이상 받을 수 있나요?**
- 예: 새출발기금 + 신용회복위원회 개인워크아웃
- 배경: 조합 생성 시 "채무조정 최대 1개"로 제한할 계획인데, 실제로 복수 수혜가 불가능한지 확인 필요
- 확인 포인트: 동시 신청 가능 여부 / 한 프로그램 이용 중 다른 프로그램 전환이 가능한지 / 새출발기금은 "평생 1회"인데 다른 채무조정 이력이 있으면 제한되는지

- 배경: 조합 생성 시 "보조금 최대 2개"로 제한할 계획. 실제 중복 한도가 몇 개인지, 동일 목적 중복 배제 조항이 있는지 확인 필요

## 문의 시 유의사항

- **같은 질문을 양쪽 기관에 교차 확인**할 것 (A-1 ↔ B-10). 기관마다 자기 자금 기준으로만 답할 수 있음
- 답변을 들으면 **근거 문서(공고문 조항, 운영규정)를 물어볼 것**. "가능합니다"만으로는 데이터에 확정값으로 넣기 어려움
- 답이 애매하면 데이터에 **"확인필요"로 유지**하고, 서비스에서는 해당 조합에 "중복 가부는 기관 확인 필요" 주의 문구를 붙이는 방식으로 처리
- 통화 후 이 문서에 **답변·확인일자·근거**를 기록해 둘 것
