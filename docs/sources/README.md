## hwp에서 표 읽는 법

한글 파일은 `pyhwp`로 표 안의 텍스트까지 뽑을 수 있다.
`hwp5txt`는 표 내용을 `<표>`로 비우고 출력하므로 XML 경로를 써야 한다.

```bash
pip install pyhwp
hwp5proc xml docs/sources/2026-1433_seoul-sme-fund.hwp > /tmp/out.xml
python3 - << 'PY'
import re
s = open('/tmp/out.xml', encoding='utf-8', errors='replace').read()
blocks = re.findall(r'<Text\b[^>]*>(.*?)</Text>', s, re.S)
print('\n'.join(t for t in (re.sub(r'<[^>]+>', '', b).strip() for b in blocks) if t))
PY
```
